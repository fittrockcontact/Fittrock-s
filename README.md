# Fittrock Sales Cockpit

Dedicated Sales Management Dashboard for Fittrock:
- Lead Tracking & Conversion Workflow
- WhatsApp Direct Follow-ups & Reminders
- Custom Manual Order Creation & Instant Dispatch
- Real-time Analytics & Pipeline Insights

## Setup & Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables:
   ```bash
   cp .env.local.example .env.local
   ```

3. Run development server:
   ```bash
   npm run dev
   ```
